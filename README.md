# ازمونک — سامانه آزمون آنلاین و نظرسنجی

سامانه‌ای کامل برای برگزاری **آزمون** و **نظرسنجی** آنلاین، ساخته‌شده با تمرکز بر زبان فارسی و
راه‌اندازی آسان روی **ویندوز** با **MySQL**.

فراگیر فقط یک **کلید آزمون** را وارد می‌کند، آزمون را می‌دهد، در پایان **نمره‌ی خود را
می‌بیند** — بدون ساخت حساب کاربری و بدون نصب هیچ برنامه‌ای.

---

## ✨ ویژگی‌ها

### سمت فراگیر
- ورود با **کلید آزمون** (کد عمومی مثل `AZM-7K2Q9` یا کد اختصاصی هر نفر مثل `ABCD-1234`)
- شروع آزمون بدون ثبت‌نام؛ دریافت نام / کد ملی / ایمیل / موبایل در صورت نیاز
- **تایمر** دقیق با ذخیره‌ی خودکار پاسخ‌ها و ثبت خودکار در پایان زمان
- ۹ نوع سوال: تک‌پاسخ، چندپاسخ، درست/نادرست، پاسخ کوتاه، پاسخ تشریحی، بارگذاری فایل،
  طیف لیکرت (نظرسنجی)، سوال ماتریسی، پاسخ عددی
- نمایش نتیجه‌ی نهایی، درصد، وضعیت قبولی و مرور پاسخ‌ها (در صورت اجازه‌ی مدیر)
- حالت **نظرسنجی ناشناس** با گزارش تجمیعی گزینه‌ها

### سمت مدیر
- **دوره‌بندی**: هر دوره می‌تواند چند آزمون و نظرسنجی داشته باشد
- **بانک سوال**: تک‌پاسخ، چندپاسخ، درست/نادرست، کوتاه، تشریحی، فایل، طیف لیکرت، ماتریسی
- **ورود اطلاعات با هوش مصنوعی**: عکس یا PDF برگه‌ی آزمون را بدهید → سوال‌ها، گزینه‌ها،
  بارم و کلید پاسخ خودکار استخراج می‌شود (مدل Claude با پشتیبانی تصویر و PDF)
- **تولید سوال** با موضوع دلخواه توسط هوش مصنوعی
- **داوری هوشمند**: پیشنهاد نمره برای پاسخ‌های تشریحی + بازخورد، تأیید و ویرایش توسط داور
- **تحلیل سوال‌به‌سوال**: درصد پاسخ درست (دشواری)، توزیع نمرات، تحلیل گزینه‌ها
- **خروجی Excel (CSV)** از نتایج، سازگار با فارسی
- کد عمومی + کد اختصاصی یک‌بارمصرف برای کنترل حضور و غیاب
- چند کاربر با نقش‌های «مدیر کل / سازنده محتوا / داور» و ثبت گزارش رویدادها

## 🏗 معماری

```
┌──────────────────────────── مرورگر فراگیر / مدیر ────────────────────────────┐
│   React 19 + TypeScript + Vite + Tailwind CSS 4 (رابط کاربری RTL فارسی)      │
└───────────────────────────────────┬──────────────────────────────────────────┘
                                    │  REST API (/api)
┌───────────────────────────────────▼──────────────────────────────────────────┐
│   Node.js 20+ / Express 5 / TypeScript / Zod (اعتبارسنجی)                   │
│                                                                              │
│  ┌────────────┐ ┌────────────┐ ┌──────────────┐ ┌────────────────────────┐   │
│  │ auth       │ │ admin API  │ │ public API   │ │ services               │   │
│  │ (JWT+کوکی) │ │ (مدیریت)   │ │ (شرکت در آزمون)│ │ grading / ai / csv    │   │
│  └────────────┘ └────────────┘ └──────────────┘ └────────────────────────┘   │
│                                                                              │
│  ┌────────────────────────────────────────────────────────────────────────┐  │
│  │ لایه داده: Kysely (Query Builder تایپ‌سیف) + Repository Pattern      │  │
│  └────────────────────────────────────────────────────────────────────────┘  │
└───────────┬──────────────────────────────────────┬───────────────────────────┘
            │                                      │
   ┌────────▼─────────┐                  ┌─────────▼──────────┐
   │   MySQL 8 /      │                  │  هوش مصنوعی        │
   │   MariaDB 10.4+  │                  │  Anthropic Claude   │
   │  (عملیاتی)       │                  │  OpenAI-compatible  │
   ├──────────────────┤                  │  Ollama (محلی)      │
   │ SQLite           │  ← حالت آزمایشی  └────────────────────┘
   └──────────────────┘
```

### چرا این معماری؟

| تصمیم | دلیل |
|---|---|
| **Kysely + Repository** | کوئری‌ها تایپ‌سیف هستند ولی SQL واقعی تولید می‌شود؛ برای گزارش‌های پیچیده‌ی آزمون عالی است |
| **MySQL + SQLite** | در محیط عملیاتی MySQL (خواسته‌ی شما) و برای ارزیابی سریع بدون نصب، SQLite — با یک کد یکسان |
| **زمان‌ها به‌صورت epoch** | رفتار یکسان در MySQL و SQLite و بدون مشکل منطقه‌ی زمانی |
| **امتیاز با ضریب ۱۰۰** | حذف کامل خطای اعشاری در نمره‌دهی (۲٫۵ نمره = ۲۵۰) |
| **سرویس واحد (SPA + API)** | روی ویندوز فقط یک پورت و یک پروسه لازم است |
| **معماری ماژولار AI** | افزودن سرویس جدید (مثلاً مدل داخلی سازمان) بدون تغییر بقیه‌ی سیستم |

### ساختار پوشه‌ها

```
azmoonak/
├── packages/shared/     # انواع، ثابت‌ها و اسکیمای Zod مشترک سرور و رابط کاربری
├── server/              # API (Express) + لایه داده + سرویس‌ها
│   ├── src/db/          # schema، مهاجرت‌ها، repository، seed
│   ├── src/routes/      # auth | public | admin
│   ├── src/services/    # grading، ai، csv، storage، sweeper
│   └── scripts/         # تست API و بررسی SQL

├── scripts/             # اسکریپت‌های راه‌اندازی ویندوز
└── .env.example         # نمونه تنظیمات
```

## 🖥 نصب روی ویندوز (گام‌به‌گام)

### گام ۱ — پیش‌نیازها

1. **Node.js نسخه ۲۰ یا بالاتر** — از [nodejs.org](https://nodejs.org) دانلود و نصب کنید
   (گزینه‌ی LTS پیشنهاد می‌شود). بعد از نصب، `node -v` را در Command Prompt بزنید.
2. **MySQL 8 یا MariaDB 10.4+**
   - ساده‌ترین راه: نصب [XAMPP](https://www.apachefriends.org) (شامل MySQL) یا
     [MySQL Installer](https://dev.mysql.com/downloads/installer/) یا
     [MariaDB](https://mariadb.org/download/) و سپس اجرای سرویس MySQL از
     **Windows Services**.

### گام ۲ — راه‌اندازی اولیه (یک بار)

دبل‌کلیک کنید روی `scripts\setup-windows.bat` — این اسکریپت:
- وجود Node.js را بررسی می‌کند
- کتابخانه‌ها را نصب می‌کند (`npm install`)
- فایل `.env` را از روی `.env.example` می‌سازد
- نسخه‌ی نهایی برنامه را می‌سازد (`npm run build`)

### گام ۳ — ساخت دیتابیس

**الف) با phpMyAdmin یا خط فرمان:**

```sql
CREATE DATABASE azmoonak CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER 'azmoonak'@'localhost' IDENTIFIED BY 'Azmoonak@123';
GRANT ALL PRIVILEGES ON azmoonak.* TO 'azmoonak'@'localhost';
FLUSH PRIVILEGES;
```

**ب) اگر Docker دارید** (فایل `docker-compose.yml` آماده است):

```bash
docker compose up -d
```

> جدول‌ها به‌صورت **خودکار** در اولین اجرای برنامه ساخته می‌شوند (مهاجرت‌های داخل پوشه‌ی
> `server/src/db/migrations.ts`).

### گام ۴ — تنظیم `.env`

فایل `.env` در ریشه‌ی پروژه را با Notepad باز کنید و حداقل این موارد را تنظیم کنید:

```ini
PORT=4000
APP_URL=http://192.168.1.20:4000     # آدرسی که فراگیران با آن وارد می‌شوند
SESSION_SECRET=یک-رشته-تصادفی-بلند-و-محرمانه

DB_MODE=mysql
MYSQL_URL=mysql://azmoonak:Azmoonak@123@127.0.0.1:3306/azmoonak

AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=کلید-شما
ANTHROPIC_MODEL=claude-sonnet-4-5
```

> بدون تنظیم `ANTHROPIC_API_KEY` همه‌ی بخش‌های برنامه کار می‌کند و فقط قابلیت‌های
> هوش مصنوعی در «حالت نمایشی» قرار می‌گیرند.

### گام ۵ — ساخت حساب مدیر و داده‌ی نمونه

```bash
npm run seed
```

خروجی: کاربر `admin` با رمز `Admin@1234` به‌همراه یک دوره، یک آزمون و یک نظرسنجی نمونه
(کدهای دسترسی در پایان ترمینال چاپ می‌شود).

### گام ۶ — اجرا

```bash
scripts\start-windows.bat
```

- صفحه‌ی فراگیر: <http://localhost:4000/>
- پنل مدیریت: <http://localhost:4000/admin>

> ⚠️ **رمز پیش‌فرض را عوض کنید**: پس از اولین ورود، از پنل مدیریت → تنظیمات، کاربران را
> ویرایش کنید.

## 🧠 هوش مصنوعی

| قابلیت | توضیح |
|---|---|
| **استخراج سوال از برگه** | عکس (JPG/PNG) یا PDF برگه‌ی آزمون را بارگذاری کنید؛ مدل متن سوال، گزینه‌ها، کلید پاسخ، بارم و دشواری را استخراج می‌کند. نتیجه پیش‌نویس است و قبل از افزوده‌شدن قابل ویرایش است. |
| **تولید سوال** | موضوع را بنویسید (مثلاً «امنیت شبکه در سازمان») و N سوال با انواع دلخواه تولید کنید. |
| **داوری هوشمند** | برای پاسخ‌های تشریحی، نمره‌ی پیشنهادی + بازخورد تولید می‌شود؛ داور آن را تأیید یا اصلاح می‌کند. |
| **خلاصه‌سازی نظرسنجی** | خلاصه‌ی نتایج و پیشنهاد اقدام. |

ارائه‌دهنده‌های پشتیبانی‌شده (با تغییر `AI_PROVIDER`):

- `anthropic` — پیشنهادی؛ Claude عکس و PDF را می‌فهمد
- `openai` — هر سرویس سازگار با OpenAI (یا مدل داخلی سازمان)
- `ollama` — مدل محلی روی همان سرور (بدون ارسال داده به بیرون)

## 🔌 خلاصه‌ی API

### عمومی (فراگیر)
| متد | مسیر | توضیح |
|---|---|---|
| `GET` | `/api/public/settings` | نام و ظاهر برنامه |
| `POST` | `/api/public/resolve` | بررسی کلید دسترسی و دریافت اطلاعات آزمون |
| `POST` | `/api/public/attempts` | شروع آزمون و دریافت توکن دسترسی |
| `GET` | `/api/public/attempts/:id` | وضعیت آزمون، سوال‌ها و پاسخ‌های ذخیره‌شده |
| `PUT` | `/api/public/attempts/:id/answers/:qid` | ذخیره‌ی خودکار یک پاسخ |
| `POST` | `/api/public/attempts/:id/upload` | بارگذاری فایل پاسخ |
| `POST` | `/api/public/attempts/:id/submit` | ثبت نهایی و دریافت نمره |
| `GET` | `/api/public/attempts/:id/result` | نتیجه‌ی نهایی |

### مدیریت
`/api/admin/*` — با هدر `Authorization: Bearer <token>`:
`overview`، `courses`، `exams`، `questions`، `invites`، `attempts`، `results` (تحلیل و CSV)،
`ai/*` (وضعیت، استخراج، تولید، داوری، خلاصه)، `uploads`، `settings`، `users`.

## 🛡 اجرای دائمی روی ویندوز (سرویس)

ساده‌ترین راه، **Task Scheduler**:

1. `Task Scheduler` → `Create Task`
2. در تب `General`: گزینه‌ی «Run whether user is logged on or not» و در `Triggers`،
   «At startup»
3. در تب `Actions`: برنامه = `C:\Program Files\nodejs\node.exe`
   و آرگومان‌ها = `server\dist\index.js` و «Start in» = مسیر پروژه
4. در تب `Settings`: تیک `If the task fails, restart every 1 minute`

راه‌های جایگزین: `pm2 start server/dist/index.js --name azmoonak` یا `nssm install Azmoonak node.exe server\dist\index.js`.

## ❓ سوالات متداول

**رمز مدیر را فراموش کرده‌ام.**
با حذف کاربر از دیتابیس و اجرای دوباره‌ی `npm run seed`، کاربر `admin` با رمز پیش‌فرض
دوباره ساخته می‌شود.

**می‌خواهم بدون MySQL سریع امتحان کنم.**
در `.env` مقدار `DB_MODE=sqlite` بگذارید. همه‌ی امکانات کار می‌کند و فایل دیتابیس در
`server/data/azmoonak.db` ساخته می‌شود.

**هوش مصنوعی کار نمی‌کند.**
از پنل مدیریت → تنظیمات → وضعیت سرویس‌ها را ببینید. اگر `AI_PROVIDER=none` یا کلید خالی
باشد، حالت نمایشی فعال است. همچنین نام مدل (`ANTHROPIC_MODEL`) باید با حساب شما سازگار باشد.

**چند فراگیر هم‌زمان از یک IP (کلاس یا شبکه مدرسه) شرکت می‌کنند.**
محدودیت نرخ برای شروع آزمون ۶۰۰ درخواست در ۵ دقیقه است و برای کلاس‌های بزرگ کافی است.
در صورت نیاز این اعداد را در `server/src/routes/public.routes.ts` تغییر دهید.

**پس از پایان زمان، فراگیر صفحه را بست.**
سرویس پاکسازی هر ۶۰ ثانیه آزمون‌های منقضی را به‌صورت خودکار ثبت و تصحیح می‌کند.
