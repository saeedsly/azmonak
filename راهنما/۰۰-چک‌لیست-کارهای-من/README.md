# ۰۰ — چک‌لیست کارهای من

این پوشه «فهرست کارهایی» است که **شما** باید انجام دهید تا ازمونک را راه بیندازید و آزمون
برگزار کنید. هر مرحله دقیقاً نوشته شده که **چه کاری، کجا و با چه دستوری** انجام شود.

---

## مرحله ۱ — نصب (یک بار برای همیشه)

- [ ] **Node.js ۲۰ یا بالاتر** را نصب کنم → <https://nodejs.org>
      (بعد از نصب، در CMD بزنید: `node -v`)
- [ ] **MySQL** را نصب کنم (XAMPP یا MySQL Installer) → بخش
      [`۰۲-نصب-ویندوز-و-xampp`](../۰۲-نصب-ویندوز-و-xampp/)
- [ ] پوشه‌ی برنامه را روی دسکتاپ کپی کنم
- [ ] در همان پوشه روی `scripts\setup-windows.bat` دوبار کلیک کنم
- [ ] در Command Prompt داخل پوشه بزنم: `npm run seed`
      (کاربر `admin` با رمز `Admin@1234` ساخته می‌شود)
- [ ] `scripts\start-windows.bat` را اجرا کنم
- [ ] در مرورگر باز کنم: `http://localhost:4000/admin` و وارد شوم
- [ ] **رمز مدیر را عوض کنم**: تنظیمات ← کاربران ← ویرایش رمز

## مرحله ۲ — آماده‌سازی محتوا

- [ ] یک **دوره** بسازم (پنل مدیریت ← دوره‌ها ← + دوره‌ی جدید)
- [ ] یک **آزمون** بسازم و به دوره وصل کنم
- [ ] سوال‌ها را وارد کنم (دستی، یا با هوش مصنوعی از روی عکس/PDF)
- [ ] تیک **گزینه‌ی درست** هر سوال را بررسی کنم ← ⚠️ مهم‌ترین کار
- [ ] بارم هر سوال را تعیین کنم
- [ ] در تب **تنظیمات**: مدت آزمون، نمره‌ی قبولی، اطلاعاتی که از فراگیر می‌خواهم
- [ ] در تب **کدهای دسترسی**: کد عمومی بسازم یا کد اختصاصی تولید کنم
- [ ] وضعیت آزمون را روی **منتشر شده** بگذارم ← تا وقتی این کار نشود، فراگیر نمی‌تواند شرکت کند

## مرحله ۳ — قبل از شروع آزمون (۱۰ دقیقه)

- [ ] یک بار کل آزمون را **خودم** به‌عنوان فراگیر امتحان کنم (کد را وارد کنم و ببینم سوال‌ها
      درست نمایش داده می‌شوند)
- [ ] تایمر و ذخیره‌ی خودکار پاسخ‌ها را چک کنم
- [ ] نتیجه‌ی نهایی (نمره، درصد، وضعیت قبولی) را ببینم
- [ ] اگر سوال تشریحی دارم: در پنل مدیریت ← **پاسخ‌ها و داوری** یکی را امتحان کنم
- [ ] کد آزمون را در کانال/گروه کلاسی یا برگه‌ی چاپی بفرستم

## مرحله ۴ — بعد از پایان آزمون

- [ ] پاسخ‌های تشریحی/فایلی را **داوری** کنم (یا از پیشنهاد هوش مصنوعی استفاده کنم)
- [ ] دکمه‌ی **نهایی‌سازی** را بزنم تا نمره‌ی فراگیران به‌روز شود
- [ ] نتایج را در **Excel** خروجی بگیرم
- [ ] تحلیل سوال‌به‌سوال را ببینم و سوال‌های خیلی سخت/خیلی آسان را اصلاح کنم

## مرحله ۵ — کارهای دوره‌ای

- [ ] هفته‌ای یک‌بار **پشتیبان** بگیرم → [`۰۸-پشتیبانی-و-بازیابی`](../۰۸-پشتیبانی-و-بازیابی/)
- [ ] نسخه‌ی برنامه را به‌روز نگه دارم (بسته‌ی جدید → جایگزینی پوشه‌ی برنامه + اجرای دوباره‌ی seed)
