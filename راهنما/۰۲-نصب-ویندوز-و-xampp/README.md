# ۰۲ — نصب روی ویندوز (با MySQL / XAMPP)

این بخش برای نصب **واقعی** روی ویندوزهای مختلف (۱۰، ۱۱، سرور) است؛ جایی که سیستم باید
همیشه در دسترس فراگیران باشد.

| فایل | موضوع |
|---|---|
| [`نصب-روی-ویندوز.md`](نصب-روی-ویندوز.md) | نصب گام‌به‌گام ویندوز + MySQL + اجرای دائمی |
| [`نصب-با-xampp.md`](نصب-با-xampp.md) | راه‌اندازی اختصاصی XAMPP (MySQL + phpMyAdmin) |

---

## خلاصه‌ی ۵ خطی

```bat
:: ۱) Node.js و XAMPP را نصب کنید
:: ۲) در phpMyAdmin دیتابیس و کاربر بسازید
:: ۳) در فایل .env مقدار DB_MODE=mysql و MYSQL_URL را بگذارید
:: ۴) نصب و ساخت:
scripts\setup-windows.bat
:: ۵) داده‌ی اولیه و اجرا:
npm run seed
scripts\start-windows.bat
```

## نکته‌های طلایی

| موضوع | توصیه |
|---|---|
| نسخه‌ی Node.js | ۲۰ یا بالاتر (LTS) — روی ویندوزهای قدیمی‌تر Node 20 امن‌تر است |
| نسخه‌ی MySQL | MySQL 8 یا MariaDB 10.4+ (XAMPP معمولاً MariaDB می‌آورد که کاملاً سازگار است) |
| پورت | اگر ۴۰۰۰ اشغال است، در `.env` مقدار `PORT=4001` بگذارید |
| شبکه‌ی مدرسه | `APP_URL=http://<IP-سرور>:4000` و باز کردن پورت در فایروال ویندوز |
| امنیت | حتماً `SESSION_SECRET` را با یک رشته‌ی تصادفی بلند جایگزین کنید و رمز admin را عوض کنید |
