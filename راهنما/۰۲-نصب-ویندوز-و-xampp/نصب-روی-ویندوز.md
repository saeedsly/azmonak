# نصب روی ویندوز — گام‌به‌گام

این راهنما برای ویندوز ۱۰، ۱۱ و سرور (2019/2022) نوشته شده است. کل فرایند حدود **۱۵ دقیقه**
طول می‌کشد.

---

## گام ۱ — پیش‌نیازها

### ۱-۱) Node.js نسخه‌ی ۲۰ یا بالاتر

1. به <https://nodejs.org> بروید و نسخه‌ی **LTS** را دانلود کنید ( installer `.msi` ).
2. حین نصب، گزینه‌ی «Add to PATH» را حتماً فعال بگذارید.
3. بررسی نصب: یک **Command Prompt** تازه باز کنید و بزنید:

```bat
node -v
npm -v
```

باید چیزی مثل `v22.x.x` و `10.x.x` ببینید. اگر «not recognized» گرفتید، ترمینال را ببندید
و دوباره باز کنید (یا سیستم را ری‌استارت کنید).

### ۱-۲) MySQL یا MariaDB

یکی از این دو:

- **XAMPP** (پیشنهادی برای اکثر کاربران) → ادامه در
  [`نصب-با-xampp.md`](نصب-با-xampp.md)
- **MySQL Installer** از <https://dev.mysql.com/downloads/installer/>
  (حین نصب، فقط «Server» و «Workbench» کافی است)

## گام ۲ — آماده کردن پوشه‌ی برنامه

1. فایل `azmoonak-v1.0.0.zip` را از حالت فشرده خارج کنید.
2. پوشه‌ی `azmoonak` را به مسیری بدون فاصله و بدون حروف فارسی کپی کنید، مثلاً:

```
C:\azmoonak
```

> ⚠️ اگر مسیر شامل حروف فارسی یا فاصله باشد، بعضی ابزارهای خط فرمان ویندوز خطا می‌دهند.

3. روی پوشه راست‌کلیک کنید → **Open in Terminal** (یا **گشودن در ترمینال**).

## گام ۳ — ساخت دیتابیس و کاربر MySQL

### با phpMyAdmin (XAMPP):

1. XAMPP را باز کنید و جلوی **MySQL** دکمه‌ی **Start** را بزنید.
2. در مرورگر: <http://localhost/phpmyadmin>
3. تب **SQL** → کد زیر را اجرا کنید:

```sql
CREATE DATABASE azmoonak CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER 'azmoonak'@'localhost' IDENTIFIED BY 'Azmoonak@123';
GRANT ALL PRIVILEGES ON azmoonak.* TO 'azmoonak'@'localhost';
FLUSH PRIVILEGES;
```

> جدول‌های برنامه **خودکار** در اولین اجرا ساخته می‌شوند؛ لازم نیست چیزی بسازید.

### با خط فرمان (MySQL روی PATH):

```bat
mysql -u root -p
```
```sql
CREATE DATABASE azmoonak CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER 'azmoonak'@'localhost' IDENTIFIED BY 'Azmoonak@123';
GRANT ALL PRIVILEGES ON azmoonak.* TO 'azmoonak'@'localhost';
FLUSH PRIVILEGES;
exit
```

## گام ۴ — تنظیم فایل `.env`

در ریشه‌ی پوشه، فایل `.env.example` را با نام `.env` کپی کنید (در Notepad باز کنید و
`File → Save As` با نام `.env` و نوع `All Files`).

مطمئن شوید این خطوط درست هستند:

```ini
PORT=4000
HOST=0.0.0.0
NODE_ENV=production
APP_URL=http://192.168.1.20:4000
SESSION_SECRET=یک-رشته-تصادفی-بلند-حداقل-۳۲-کاراکتری
DB_MODE=mysql
MYSQL_URL=mysql://azmoonak:Azmoonak@123@127.0.0.1:3306/azmoonak
```

| کلید | توضیح |
|---|---|
| `APP_URL` | آدرسی که فراگیران در مرورگر می‌زنند (IP این کامپیوتر در شبکه) |
| `SESSION_SECRET` | کلید امضای نشست‌ها؛ **حتماً** تغییرش بدهید |
| `MYSQL_URL` | نام کاربر، رمز، آدرس و نام دیتابیس |
| `CORS_ORIGINS` | اگر فقط روی همین سرور اجرا می‌شود، `*` مشکلی ندارد |

> اگر رمز دیتابیس شما شامل `@` یا `#` است، در آدرس باید به شکل `%40` و `%23` نوشته شود.

## گام ۵ — نصب کتابخانه‌ها و ساخت برنامه

```bat
scripts\setup-windows.bat
```

این اسکریپت: وجود Node را چک می‌کند → `npm install` → ساخت `.env` (اگر نباشد) →
`npm run build`.

> اگر پیام «درایور SQLite نصب نشد» دیدید، **نگران نشوید** — در حالت MySQL به آن نیازی نیست.

## گام ۷ — اجرا

```bat
scripts\start-windows.bat
```

پنجره‌ای باز می‌شود و آدرس‌ها را نشان می‌دهد. برای توقف: `Ctrl + C`.

| آدرس | چه می‌بینید |
|---|---|
| <http://localhost:4000/> | صفحه‌ی فراگیر |
| <http://localhost:4000/admin> | پنل مدیریت |

> 🔐 **بلافاصله بعد از اولین ورود:** رمز `admin` را در «تنظیمات ← کاربران» عوض کنید.

---

## گام ۸ — دسترسی از کامپیوترهای دیگر

1. IP این کامپیوتر را پیدا کنید: در CMD بزنید `ipconfig` → خط `IPv4 Address`.
2. فایروال ویندوز را باز کنید:
   `Windows Defender Firewall → Advanced settings → Inbound Rules → New Rule → Port → TCP → 4000`
   (یا ساده‌تر: هنگام اولین اجرا، ویندوز خودش می‌پرسد؛ **Private networks** را تیک بزنید و Allow کنید)
3. `APP_URL` را در `.env` به همین IP تغییر دهید و برنامه را دوباره اجرا کنید.

## ✈️ نصب روی شبکه‌ی مدرسه/شرکت — خلاصه

| مورد | مقدار |
|---|---|
| آدرس فراگیران | `http://192.168.1.20:4000/` |
| آدرس پنل مدیر | `http://192.168.1.20:4000/admin` |
| پورت | ۴۰۰۰ (یا هر پورت آزاد) |
| فایروال | پورت را باز کنید |
| روتر | اگر فراگیران در اینترنت‌اند، پورت را روی روتر Forward کنید (و HTTPS را ترجیح دهید) |
