## ۲) لایه‌ها و مسئولیت‌ها

| لایه | فایل‌ها | مسئولیت |
|---|---|---|
| **shared** | `packages/shared/src` | انواع DTO، ثابت‌ها (انواع سوال/وضعیت‌ها)، اسکیمای Zod مشترک |
| **routes** | `server/src/routes` | مسیرها، خواندن ورودی، پاسخ HTTP — **بدون** منطق کسب‌وکار |
| **middleware** | `server/src/middleware` | نشست مدیر، آپلود فایل، مدیریت خطا و لاگ |
| **services** | `server/src/services` | منطق دامنه: دسترسی، داوری، نمای عمومی، تلاش، AI، CSV، ذخیره‌سازی، پاک‌سازی |
| **db** | `server/src/db` | Kysely، مهاجرت‌ها، repository‌ها، mapperها، seed |
| **lib** | `server/src/lib` | ابزارهای کوچک: JWT، کد دسترسی، خطاها، shuffle |
| **web** | `web/src` | رابط کاربری: صفحات فراگیر + پنل مدیریت |

## ۳) جریان یک آزمون (از کلید تا نمره)

```
۱) فراگیر: POST /api/public/resolve { code }
      ← سرویس access: کد را نرمال و پیدا می‌کند، وضعیت/بازه/سقف تلاش را بررسی می‌کند
      ← پاسخ: عنوان، تعداد سوال، مدت، نمره‌ی قبولی، اینکه چه مشخصاتی لازم است

۲) فراگیر: POST /api/public/attempts { accessCode, name, email, ... }
      ← بررسی سقف تلاش برای همان هویت
      ← upsertParticipant (به‌جز در حالت ناشناس)
      ← ساخت رکورد attempt + توکن اختصاصی تلاش (JWT با audience=participant)

۳) فراگیر: GET /api/public/attempts/:id  (با هدر X-Attempt-Token)
      ← سرویس publicView: تبدیل سوال‌ها به DTO عمومی (بدون کلید پاسخ!)

۴) فراگیر: PUT /api/public/attempts/:id/answers/:questionId
      ← ذخیره‌ی هر پاسخ (autosave)

۵) فراگیر: POST /api/public/attempts/:id/submit
      ← سرویس grading: محاسبه‌ی نمره، درصد، وضعیت قبولی
      ← سرویس publicView: ساخت payload نتیجه (پاسخ درست فقط اگر مدیر اجازه داده باشد)

۶) سرویس sweeper (هر ۳۰ ثانیه): تلاش‌های منقضی‌شده را خودکار نهایی می‌کند
```

## ۴) تصمیم‌های فنی و دلیلشان

| تصمیم | دلیل |
|---|---|
| **مونوریپو با ۳ workspace** (`packages/shared`, `server`, `web`) | تایپ‌ها و اعتبارسنجی بین سرور و رابط یکی بماند؛ ساخت یکپارچه |
| **Kysely به‌جای Prisma/TypeORM** | یک لایه‌ی کوچک و قابل‌کنترل روی SQL؛ پشتیبانی هم‌زمان MySQL و SQLite با یک کد |
| **مهاجرت‌های خودکار در زمان اجرا** | نصب روی ویندوز بدون ابزار اضافه؛ جدول‌ها در اولین اجرا ساخته می‌شوند |
| **JWT برای نشست مدیر + توکن جدا برای تلاش فراگیر** | دو دامنه‌ی امنیتی مستقل: توکن فراگیر فقط به همان تلاش دسترسی دارد |
| **نمره با ضریب ۱۰۰ در دیتابیس** | اعشار (۰.۵ نمره) بدون نوع float ذخیره می‌شود |
| **بارم سوال = واحد نمره** (`points`) | مجموع بارم‌ها = نمره‌ی کل آزمون، بدون محاسبه‌ی تکراری |
| **بارگذاری فایل با Multer + ذخیره در `data/uploads`** | فایل‌ها روی دیسک می‌مانند (قابل پشتیبان‌گیری) و با URL عمومی سرو می‌شوند |
| **سوییپر برای تلاش‌های منقضی** | حتی اگر فراگیر مرورگر را ببندد، نمره‌اش ثبت می‌شود |
| **رابط کاملاً RTL با فونت وزیرمتن** | تجربه‌ی فارسی بدون دانلود فونت از اینترنت |

## ۵) امنیت

| موضوع | پیاده‌سازی |
|---|---|
| رمز مدیر | `bcryptjs` (هش) |
| نشست مدیر | JWT امضاشده با `SESSION_SECRET`، انقضا پیش‌فرض ۱۲ ساعت |
| توکن تلاش | JWT جدا با `audience=participant` و فقط برای همان `attemptId` |
| محدودیت نرخ | rate-limit روی ورود، resolve، شروع تلاش و نوشتن پاسخ |
| اعتبارسنجی ورودی | Zod در همه‌ی مسیرها (`parseSafe`) |
| هدرهای امنیتی | `helmet` |
| SQL Injection | همه‌ی کوئری‌ها پارامتری (Kysely) |
| آپلود | محدودیت حجم (پیش‌فرض ۲۵MB) + پسوند/میم‌تایپ کنترل‌شده |
| CORS | از `.env` قابل تنظیم |
| گزارش رویداد | جدول `audit_logs` برای ورود و عملیات حساس |

## ۶) هوش مصنوعی

| قابلیت | مسیر |
|---|---|
| استخراج سوال از عکس/PDF | `services/aiTasks.ts → extractQuestions` |
| تولید سوال | `generateQuestions` |
| پیشنهاد نمره | `suggestGrades` |
| خلاصه‌سازی نظرسنجی | `summarizeSurvey` |

-providerها: `anthropic` (با پشتیبانی تصویر/PDF)، `openai` (سازگار با OpenAI)، `ollama` (محلی)،
`none` (حالت نمایشی). انتخاب با `AI_PROVIDER` در `.env`.

> همه‌ی درخواست‌های AI در جدول `ai_jobs` ثبت می‌شوند (وضعیت، ورودی، خروجی، خطا) تا از
> پنل مدیریت قابل پیگیری باشد.

## ۷) اجرای دو حالت دیتابیس

| حالت | تنظیم | کاربرد |
|---|---|---|
| MySQL | `DB_MODE=mysql` + `MYSQL_URL` | محیط عملیاتی، XAMPP، چند کاربر هم‌زمان |
| SQLite | `DB_MODE=sqlite` + `SQLITE_FILE` | توسعه، تست سریع، نصب بدون MySQL |

کد یکسان است؛ فقط dialect کِیسِلی عوض می‌شود (`server/src/db/index.ts`).
