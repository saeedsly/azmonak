# ۰۵ — معماری و ساختار کد

این بخش توضیح می‌دهد ازمونک **از داخل** چطور کار می‌کند؛ برای وقتی که می‌خواهید سیستم را
تغییر دهید یا توسعه دهید.

| فایل | موضوع |
|---|---|
| [`معماری.md`](معماری.md) | لایه‌ها، جریان داده و تصمیم‌های فنی |
| [`ساختار-پوشه‌ها.md`](ساختار-پوشه‌ها.md) | توضیح تک‌تک پوشه‌ها و فایل‌های پروژه |
| [`مدل-داده.md`](مدل-داده.md) | جدول‌های پایگاه داده و ارتباطشان |

---

## خلاصه‌ی ۱۰ ثانیه‌ای

```
مرورگر (React/Vite)  ──HTTP/JSON──▶  سرور (Express + Kysely)  ──▶  MySQL / SQLite
        ▲                                    │
        └──────────────  فایل‌های SPA ──────┘
```

- **سرور**: Node.js + Express 5 + Kysely (لایه‌ی داده) + JWT (نشست) + Multer (آپلود) + Zod (اعتبارسنجی)
- **رابط**: React 19 + Vite 7 + Tailwind 4 (کاملاً RTL، فونت وزیرمتن)
- **مشترک**: پکیج `packages/shared` برای انواع، ثابت‌ها و اسکیمای Zod
- **پایگاه داده**: MySQL 8 (اصلی) یا SQLite (توسعه/تست) — هر دو با یک کد
