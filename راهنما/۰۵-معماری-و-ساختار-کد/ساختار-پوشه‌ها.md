# ساختار پوشه‌ها — راهنمای فایل‌به‌فایل

> هر پوشه و فایل اینجا توضیح داده شده. این سند را وقتی بخوانید که می‌خواهید بدانید «این
> فایل دقیقاً چه کاری انجام می‌دهد».

## ریشه‌ی پروژه

| مسیر | توضیح |
|---|---|
| `README.md` | **نقشه‌ی پروژه** + مستندات فنی کامل (معماری، نصب، API، امنیت) |
| `package.json` | اسکریپت‌های npm در سطح ریشه (build/test/release/…) و تعریف workspace‌ها |
| `package-lock.json` | نسخه‌ی دقیق dependencyها |
| `.env.example` | نمونه‌ی تنظیمات — این فایل را به `.env` کپی کنید |
| `docker-compose.yml` | MySQL 8.4 آماده برای توسعه (با پورت ۳۳۰۶) |
| `راهنما/` | همه‌ی مستندات فارسی، دسته‌بندی‌شده (۱۰ پوشه) |
| `استقرار/` | فایل‌های آماده‌ی استقرار: nginx / systemd / xampp / docker / اسکریپت پشتیبان |
| `scripts/` | اسکریپت‌های اجرایی (نام انگلیسی تا در CMD ویندوز بی‌دردسر کار کند) |
| `release/` | بسته‌ی ZIP قابل تحویل (با `npm run release` ساخته می‌شود؛ در git نیست) |

### `scripts/`

| فایل | کار |
|---|---|
| `setup-windows.bat` | نصب یک‌باره: چک Node → `npm install` → ساخت `.env` → `npm run build`. با آرگومان `sqlite` حالت بدون MySQL را می‌سازد |
| `start-windows.bat` | اجرای نسخه‌ی ساخته‌شده (`node server\dist\index.js`) |
| `test-api-windows.bat` | اجرای تست API (`npx tsx server\scripts\smoke-test.ts`) |
| `build-release.mjs` | ساخت بسته‌ی ZIP قابل تحویل (بدون وابستگی خارجی) |
| `build-release.bat` | همان کار با دوبار کلیک در ویندوز |
| `smoke-test.sh` | همان تست API برای لینوکس/مک |

## `packages/shared/` — قرارداد مشترک

| فایل | محتوا |
|---|---|
| `src/types.ts` | انواع DTO که بین سرور و رابط رد و بدل می‌شوند (ExamDto, QuestionDto, PublicQuestionDto, …) |
| `src/constants.ts` | ثابت‌ها: انواع سوال، وضعیت آزمون، نقش‌ها، برچسب‌های فارسی |
| `src/schemas.ts` | اسکیمای Zod برای اعتبارسنجی ورودی API (ساخت/ویرایش آزمون، سوال، کاربر، …) |
| `src/index.ts` | نقطه‌ی خروجی پکیج |

> ⚠️ نکته‌ی مهم: برای اسکیماهای «ویرایش»، شکل پایه بدون `.default()` جدا تعریف شده است، چون در
> Zod نسخه‌ی ۴ متد `.partial()` روی فیلدهای دارای مقدار پیش‌فرض، آن مقادیر را اعمال می‌کند و
> ویرایش جزئی را به ریست کامل تبدیل می‌کند.

## جریان یک درخواست (خلاصه)

```
routes/*.ts
  → parseSafe(schema, req.body)        // اعتبارسنجی Zod
  → middleware (requireAuth / requireAttempt)
  → services/*.ts                       // منطق
  → db/repos.ts                         // کوئری Kysely
  → res.json(...)                       // پاسخ
```

خطاها با `AppError` پرتاب می‌شوند و در `middleware/error.ts` به پاسخ فارسی با کد HTTP تبدیل
می‌گردند؛ خطاهای ناشناخته با `500` و لاگ کامل برمی‌گردند.
