# مدل داده

همه‌ی جدول‌ها در **اولین اجرای برنامه** خودکار ساخته می‌شوند (مهاجرت‌های
`server/src/db/migrations.ts`). نیازی به اجرای دستی SQL نیست.

---

## نقشه‌ی ارتباط جدول‌ها

```
courses ──1:N──▶ exams ──1:N──▶ questions
                    │
                    ├──1:N──▶ attempts ──1:N──▶ answers
                    │            │
                    │            └──0:1──▶ participants
                    │
                    └──1:N──▶ invites

users ──1:N──▶ exams (createdBy)
users ──1:N──▶ ai_jobs (createdBy)
app_settings (key/value)
audit_logs (رویدادها)
schema_migrations (تاریخچه‌ی مهاجرت)
```

---

## جدول‌ها

### `users` — کاربران پنل مدیریت
| ستون | نوع | توضیح |
|---|---|---|
| `id` | varchar(191) | کلید اصلی (UUID) |
| `username` | varchar(191) | یکتا — نام کاربری ورود |
| `email` | varchar(191) | اختیاری |
| `passwordHash` | varchar(191) | هش bcrypt |
| `fullName` | varchar(191) | نام کامل |
| `role` | varchar(32) | `ADMIN` / `EDITOR` / `REVIEWER` |
| `isActive` | integer | ۱ فعال، ۰ غیرفعال |
| `lastLoginAt` | bigint | آخرین ورود |
| `createdAt` / `updatedAt` | bigint | زمان‌ها (میلی‌ثانیه) |

> کاربر اولیه: `admin` / `Admin@1234` با نقش `ADMIN` (توسط `npm run seed`).

### `courses` — دوره‌ها
`id`, `title`, `description`, `code`, `instructor`, `color`, `isArchived`, `createdBy`,
`createdAt`, `updatedAt`

### `exams` — آزمون‌ها و نظرسنجی‌ها
| ستون | توضیح |
|---|---|
| `id` | UUID |
| `courseId` | دوره (nullable) |
| `title`, `description`, `instructions` | متن‌ها |
| `type` | `EXAM` (آزمون) یا `SURVEY` (نظرسنجی) |
| `status` | `DRAFT` / `PUBLISHED` / `CLOSED` |
| `accessCode` | کد یکتای ورود (مثل `AZM-LVFR`) |
| `durationMinutes` | مدت آزمون (۰ = بدون محدودیت) |
| `maxAttempts` | سقف تلاش برای هر فراگیر (۰ = نامحدود) |
| `shuffleQuestions` / `shuffleOptions` | بُر زدن سوال/گزینه |
| `showResultImmediately` | نمایش نتیجه بلافاصله بعد از submit |
| `showCorrectAnswers` | نمایش کلید پاسخ به فراگیر |
| `showPerQuestionFeedback` | نمایش توضیح هر سوال |
| `passScore` | نمره‌ی قبولی (درصد) |
| `startAt` / `endAt` | بازه‌ی برگزاری (nullable) |
| `requireName` / `requireEmail` / `requirePhone` / `requireNationalCode` | چه مشخصاتی لازم است |
| `allowAnonymous` | شرکت ناشناس (فقط نظرسنجی) |
| `createdBy`, `createdAt`, `updatedAt` | ردیابی |

### `questions` — سوال‌ها
| ستون | توضیح |
|---|---|
| `id`, `examId` | کلید و ارتباط با آزمون |
| `orderIndex` | ترتیب نمایش |
| `type` | یکی از ۹ نوع سوال |
| `title`, `description`, `imageUrl` | متن و تصویر سوال |
| `points` | بارم (واحد نمره، ×۱۰۰ ذخیره می‌شود) |
| `explanation` | پاسخ تشریحی/راهنما |
| `difficulty` | ۱ تا ۵ |
| `tags` | JSON آرایه‌ی برچسب‌ها |
| `isRequired` | سوال اجباری (★) |
| `allowPartialCredit` | نمره‌ی جزئی در چندپاسخی |
| `options` | JSON آرایه‌ی گزینه‌ها: `{id, text, isCorrect, order}` |
| `matrixConfig` | JSON: سطرها/ستون‌ها/کلید |
| `ratingConfig` | JSON: کمینه/بیشینه/برچسب‌ها (طیف لیکرت) |
| `source` | `MANUAL` / `AI` / `IMPORT` |
| `isApproved` | تأیید مدیر برای سوال‌های AI |
| `aiMeta` | JSON فراداده‌ی تولید AI |
| `createdAt`, `updatedAt` | زمان‌ها |

### `participants` — فراگیران
`id`, `fullName`, `email`, `phone`, `nationalCode`, `meta` (JSON), `createdAt`, `updatedAt`

> در **نظرسنجی ناشناس** هیچ رکوردی در این جدول ساخته نمی‌شود.

### `attempts` — تلاش‌ها (هر فراگیر در هر آزمون)
| ستون | توضیح |
|---|---|
| `id`, `examId`, `participantId` | شناسه و ارتباط‌ها |
| `participantName` / `participantEmail` / `participantPhone` / `participantNationalCode` | کپی مشخصات در لحظه‌ی شرکت (برای نمایش سریع) |
| `isAnonymous` | ۱ برای نظرسنجی ناشناس |
| `status` | `IN_PROGRESS` / `SUBMITTED` / `GRADED` |
| `startedAt`, `expiresAt`, `submittedAt` | زمان‌ها |
| `durationUsedSec` | مدت پاسخ‌دهی (ثانیه) |
| `score` / `maxScore` | نمره (×۱۰۰) |
| `passed` | ۱ قبول، ۰ مردود، null نامشخص (نیاز به داوری) |
| `accessCodeUsed` | کدی که فراگیر استفاده کرد |
| `ip`, `userAgent` | اثر انگشت مرورگر |
| `gradedBy`, `gradedAt`, `gradingNotes` | اطلاعات داور |
| `createdAt`, `updatedAt` | زمان‌ها |

### `answers` — پاسخ‌ها
`id`, `attemptId`, `questionId`, `value` (JSON), `isCorrect`, `pointsAwarded` (×۱۰۰),
`maxPoints`, `needsManualGrading`, `feedback`, `gradedBy`, `gradedAt`, `createdAt`, `updatedAt`

> `needsManualGrading` برای سوال‌های تشریحی/کوتاه/عددی/فایلی = ۱ است.

### `invites` — کدهای اختصاصی
`id`, `examId`, `code` (یکتا), `label`, `maxUses`, `usedCount`, `expiresAt`, `isActive`,
`createdAt`

### `ai_jobs` — کارهای هوش مصنوعی
`id`, `kind` (`EXTRACT_QUESTIONS`/`GENERATE_QUESTIONS`/`SUGGEST_GRADES`/`SUMMARIZE_SURVEY`),
`status` (`PENDING`/`DONE`/`FAILED`), `inputMeta` (JSON), `result` (JSON), `error`,
`createdBy`, `createdAt`, `finishedAt`

### `app_settings`
`key` (کلید اصلی), `value` (JSON), `updatedAt` — برای تنظیمات داخل پنل (مثلاً کلید AI)

### `audit_logs`
`id`, `userId`, `action`, `entity`, `entityId`, `meta` (JSON), `ip`, `createdAt`

### `schema_migrations`
`name` (کلید اصلی), `appliedAt` — فهرست مهاجرت‌های اجراشده

## نکته‌های فنی

| موضوع | توضیح |
|---|---|
| **نمره‌ی اعشاری** | همه‌ی نمره‌ها ×۱۰۰ ذخیره می‌شوند (مثلاً ۰.۵ نمره = `50`) تا خطای float رخ ندهد |
| **زمان‌ها** | همه `bigint` به‌صورت میلی‌ثانیه (`Date.now()`) |
| **JSON در ستون متنی** | ستون‌های `options`، `tags`، `meta`، `matrixConfig` با `stringifyJson` ذخیره و با `parseJson` خوانده می‌شوند |
| **ایندکس‌ها** | روی `exams.courseId`، `questions.examId`، `attempts.examId`، `answers.attemptId`، `answers.questionId`، `invites.examId`، `audit_logs.createdAt` |
| **حذف آبشاری** | حذف آزمون → تلاش‌ها، سوال‌ها و کدهای آن هم پاک می‌شوند؛ حذف دوره فقط `courseId` آزمون‌ها را خالی می‌کند |
| **مهاجرت ۲** | `002_participants_updated_at` ستون `updatedAt` را به جدول `participants` اضافه می‌کند (برای نصب‌های قدیمی) |
