# ۰۱ — شروع سریع (بدون MySQL)

هدف این بخش: در **۵ دقیقه** برنامه را روی کامپیوتر خودتان بالا بیاورید و ببینید چطور کار
می‌کند — بدون نصب MySQL و بدون تنظیم دیتابیس.

| فایل | موضوع |
|---|---|
| [`راهنمای-اجرا.md`](راهنمای-اجرا.md) | راهنمای کامل و گام‌به‌گام اجرا (پیشنهاد می‌شود همین را بخوانید) |

---

## خلاصه‌ی ۵ دقیقه‌ای

```bat
:: ۱) نصب یک‌باره‌ی کتابخانه‌ها + ساخت برنامه (با فایل .env در حالت SQLite)
scripts\setup-windows.bat sqlite

:: ۲) ساخت کاربر مدیر و داده‌ی نمونه
npm run seed

:: ۳) اجرا
scripts\start-windows.bat
```

سپس در مرورگر:

| آدرس | چه می‌بینید |
|---|---|
| <http://localhost:4000/> | صفحه‌ی فراگیر (ورود با کد آزمون) |
| <http://localhost:4000/admin> | پنل مدیریت (`admin` / `Admin@1234`) |

## کدهای نمونه (بعد از `npm run seed`)

| نوع | کد |
|---|---|
| آزمون | `AZM-LVFR` |
| نظرسنجی | `AZM-JREH` |

> این حالت برای **دیدن و آزمایش** است. داده‌ها در `server\data\azmoonak.db` ذخیره می‌شود و
> برای محیط واقعی (مدرسه/شرکت) باید از **MySQL** استفاده کنید →
> [`۰۲-نصب-ویندوز-و-xampp`](../۰۲-نصب-ویندوز-و-xampp/)
