# پشتیبان‌گیری و بازیابی

---

## ۱) چه چیزهایی باید پشتیبان بگیرید؟

| مورد | مسیر در حالت MySQL | مسیر در حالت SQLite |
|---|---|---|
| پایگاه داده (همه‌ی نمره‌ها و آزمون‌ها) | دیتابیس `azmoonak` روی MySQL | فایل `server\data\azmoonak.db` |
| فایل‌های آپلودی (عکس سوال، پاسخ فایلی) | `server\data\uploads\` | همان |
| تنظیمات | فایل `.env` (مهم: شامل رمز دیتابیس) | همان |

---

## ۲) پشتیبان‌گیری با اسکریپت آماده (پیشنهادی)

```bat
powershell -ExecutionPolicy Bypass -File "استقرار\windows\backup-mysql.ps1"
```

خروجی در پوشه‌ی `backups\` ساخته می‌شود:
```
backups\azmoonak-2026-01-31_2300.sql     ← پایگاه داده
backups\uploads-2026-01-31_2300.zip       ← فایل‌های آپلودی
```
پشتیبان‌های قدیمی‌تر از ۳۰ روز به‌صورت خودکار حذف می‌شوند.

### زمان‌بندی خودکار روزانه

۱) Task Scheduler → **Create Task**
۲) تب **General**: Name = `Azmoonak-Backup`، ✅ «Run whether user is logged on or not»
۳) تب **Triggers** → New → **Daily** → ساعت **23:00**
۴) تب **Actions** → New:
   - Program: `powershell.exe`
   - Arguments: `-ExecutionPolicy Bypass -File "C:\azmoonak\استقرار\windows\backup-mysql.ps1"`
   - Start in: `C:\azmoonak`
۵) OK

> 💡 اگر مسیر فارسی پوشه مشکل‌ساز شد، اسکریپت را در مسیر انگلیسی (مثلاً `C:\azmoonak-backup.ps1`)
> کپی کنید و همان را در Task Scheduler صدا بزنید.

---

## ۳) پشتیبان‌گیری دستی (بدون اسکریپت)

### روش الف — phpMyAdmin (XAMPP)
۱) <http://localhost/phpmyadmin> → دیتابیس `azmoonak`
۲) تب **Export** → **Quick** → SQL → **Go**
۳) فایل `.sql` دانلود می‌شود.

### روش ب — خط فرمان (mysqldump)
```bat
:: پشتیبان پایگاه داده
mysqldump -u azmoonak -p --single-transaction --default-character-set=utf8mb4 azmoonak > D:\backup\azmoonak-2026-01-31.sql

:: پشتیبان فایل‌های آپلودی
powershell -Compress-Archive -Path "server\data\uploads" -DestinationPath "D:\backup\uploads-2026-01-31.zip"
```

### روش ج — حالت SQLite
کافی است فایل `server\data\azmoonak.db` را کپی کنید (برنامه را نبندید یا پس از بستن
برنامه کپی بگیرید تا فایل خراب نشود).

---

## ۴) بازیابی

### با اسکریپت
```bat
استقرار\windows\restore-mysql.bat backups\azmoonak-2026-01-31_2300.sql
```

### با phpMyAdmin
۱) دیتابیس `azmoonak` → تب **Import** → فایل `.sql` را انتخاب کنید → **Go**
۲) فایل ZIP آپلودها را در `server\data\uploads` باز کنید (جایگزین کنید).
۳. سرویس را دوباره اجرا کنید.

> ⚠️ بازیابی، داده‌های فعلی را **جایگزین** می‌کند. قبل از بازیابی یک پشتیبان تازه بگیرید.

---

## ۵) بازگرداندن سریع برنامه روی سیستم جدید

۱. پوشه‌ی برنامه را کپی کنید → `npm install` → `npm run build`
۲. MySQL را نصب و سرویس را اجرا کنید
۳. دیتابیس خالی `azmoonak` را بسازید (مثل راهنمای نصب)
۴. فایل `.env` را از سیستم قبلی کپی کنید (یا بر اساس راهنمای نصب بسازید)
۵. فایل پشتیبان `.sql` را import کنید
۶. پوشه‌ی `server\data\uploads` را کپی کنید
۷. `scripts\start-windows.bat` را اجرا کنید

---

## ۶) چک‌لیست سلامت پشتیبان

- [ ] آخرین فایل پشتیبان **کمتر از ۲۴ ساعت** پیش ساخته شده؟
- [ ] حجم فایل `.sql` منطقی است (نه صفر، نه خیلی کوچک)؟
- [ ] یک‌بار **بازیابی آزمایشی** روی یک سیستم دیگر انجام داده‌ام؟
- [ ] نسخه‌ای از فایل‌ها روی فلش/هارد خارجی یا فضای ابری دارم؟
- [ ] `uploads` هم پشتیبان می‌شود (نه فقط دیتابیس)؟
