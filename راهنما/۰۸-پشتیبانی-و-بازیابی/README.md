## اصل طلایی

> **دو چیز را باید پشتیبان بگیرید:**
> ۱) **پایگاه داده** (آزمون‌ها، سوال‌ها، نمره‌ها، کاربران)
> ۲) **فایل‌های بارگذاری‌شده** (عکس سوال‌ها و فایل پاسخ فراگیران) در `server\data\uploads`

بدون مورد ۲، فایل‌های آپلودی از بین می‌روند؛ بدون مورد ۱، همه‌ی نمره‌ها از بین می‌رود.
