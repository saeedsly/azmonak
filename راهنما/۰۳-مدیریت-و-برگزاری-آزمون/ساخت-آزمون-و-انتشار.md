# ساخت آزمون و انتشار

---

## گام ۱ — ساخت دوره

`پنل مدیریت ← دوره‌ها ← + دوره‌ی جدید`

| فیلد | توضیح |
|---|---|
| **عنوان** | مثلاً «شبکه‌های کامپیوتری ۱» |
| **کد دوره** | اختیاری؛ برای گزارش‌گیری و مرتب‌سازی |
| **مدرس** | اختیاری |
| **رنگ** | برای تشخیص سریع دوره در لیست آزمون‌ها |

هر دوره می‌تواند **چند آزمون و چند نظرسنجی** داشته باشد (مثلاً آزمون میان‌ترم + آزمون پایانی).

---

## گام ۲ — ساخت آزمون

`پنل مدیریت ← آزمون‌ها ← + آزمون جدید`

| فیلد | گزینه‌ها | پیشنهاد |
|---|---|---|
| **نوع** | آزمون / نظرسنجی | برای نمره‌داری: «آزمون» |
| **وضعیت** | پیش‌نویس / منتشر شده / بسته شده | تا قبل از آزمون: **پیش‌نویس** |
| **مدت آزمون** | دقیقه (۰ = بدون محدودیت) | ۳۰ تا ۶۰ دقیقه |
| **حداکثر دفعات شرکت** | عدد (۰ = نامحدود) | ۱ برای آزمون پایانی |
| **نمره‌ی قبولی** | درصد | ۵۰ تا ۶۰ |
| **بُر زدن سوال‌ها** | روشن/خاموش | روشن برای جلوگیری از تقلب |
| **بُر زدن گزینه‌ها** | روشن/خاموش | اختیاری |
| **نمایش فوری نتیجه** | روشن/خاموش | روشن |
| **نمایش پاسخ درست** | روشن/خاموش | معمولاً خاموش؛ اگر روشن باشد فراگیر کلید را می‌بیند |
| **بازخورد هر سوال** | روشن/خاموش | توضیح/راهنمای هر سوال |
| **دریافت نام/ایمیل/تلفن/کد ملی** | چک‌باکس | حداقل نام را روشن کنید |
| **شرکت ناشناس** | روشن/خاموش | فقط برای نظرسنجی |
| **زمان شروع/پایان** | تاریخ و ساعت | اختیاری — برای «بازه‌ی برگزاری» |
| **دوره** | انتخاب از دوره‌های ساخته‌شده | اتصال به دوره |

پس از ساخت، یک **کد دسترسی** خودکار (مثل `AZM-7K2Q9`) تولید می‌شود. این کد را می‌توانید
در تب «کدهای دسترسی» عوض کنید (`regenerate-code`).

---

## گام ۳ — زمان‌بندی انتشار

دو سطح زمان‌بندی وجود دارد:

| سطح | تنظیم | رفتار برنامه |
|---|---|---|
| **بازه‌ی برگزاری** | `startAt` / `endAt` | قبل/بعد از این بازه، فراگیر نمی‌تواند شروع کند |
| **مدت آزمون** | `durationMinutes` | تایمر هر فراگیر؛ در پایان زمان، پاسخ‌ها خودکار ثبت می‌شود |

> 💡 اگر می‌خواهید نتیجه بعداً و پس از داوری به فراگیر نشان داده شود، «نمایش فوری نتیجه» را
> **خاموش** کنید و بعد از داوری، «نهایی‌سازی» را بزنید.

---

## گام ۴ — کدهای دسترسی

تب **کدهای دسترسی** دو نوع کد دارد:

### کد عمومی
یک کد مشترک برای همه (مثل `AZM-LVFR`).
- ✅ سریع‌ترین راه برای کلاس‌های بزرگ
- ⚠️ حضور و غیاب دقیق ممکن نیست

### کد اختصاصی (Invite)
با دکمه‌ی «تولید کد» می‌توانید ۱ تا ۲۰۰ کد یک‌بارمصرف بسازید:

| گزینه | کاربرد |
|---|---|
| **تعداد** | چند کد ساخته شود (مثلاً ۳۰ کد برای ۳۰ نفر) |
| **برچسب** | مثلاً «کلاس ۳-الف» — در فهرست شرکت‌کنندگان می‌بینید کدام برچسب شرکت کرده |
| **حداکثر استفاده** | معمولاً ۱ (یک‌بارمصرف) |
| **انقضا** | اختیاری — کد بعد از این تاریخ کار نمی‌کند |

> هر کد اختصاصی، همان مدرک حضور و غیاب شماست: در فهرست تلاش‌ها، «کد استفاده‌شده» ثبت می‌شود.

---

## گام ۵ — انتشار

تب **تنظیمات ← وضعیت = منتشر شده** ← ذخیره.

> ⚠️ تا وقتی وضعیت «پیش‌نویس» باشد، فراگیر با کد می‌گوید «این آزمون هنوز منتشر نشده است».

---

## گام ۶ — تست نهایی قبل از انتشار

قبل از اعلام به فراگیران:

1. در یک **مرورگر دیگر** (یا حالت ناشناس) `http://localhost:4000/` را باز کنید.
2. کد آزمون را وارد کنید → مشخصات خود را بنویسید → شروع.
3. یک سوال را جواب بدهید و ببینید ذخیره شد.
4. ثبت نهایی کنید و نمره، درصد و وضعیت قبولی را ببینید.
5. بعد از این تست، **تلاش آزمایشی خودتان را حذف کنید** (از فهرست تلاش‌ها) تا در آمار
   نهایی اشتباه ایجاد نشود.

## ❗ نکته‌های مهم

| موضوع | توضیح |
|---|---|
| ویرایش آزمونِ در حال برگزاری | تغییر سوال‌ها بعد از شروع آزمون، نمره‌ی تلاش‌های قبلی را به‌هم می‌ریزد؛ تا پایان آزمون صبر کنید |
| تیک «گزینه‌ی درست» | اگر اشتباه باشد، نمره‌ی فراگیران اشتباه حساب می‌شود — همیشه چک کنید |
| حذف آزمون | با حذف آزمون، همه‌ی تلاش‌ها و نمرات آن هم پاک می‌شود؛ قبلش خروجی Excel بگیرید |
| کپی آزمون | دکمه‌ی «کپی» یک نسخه‌ی جدید (پیش‌نویس) با همان سوال‌ها می‌سازد |
