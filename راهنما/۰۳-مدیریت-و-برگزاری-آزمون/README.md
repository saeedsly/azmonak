## 🗺 مسیر کار در پنل مدیریت

```
پنل مدیریت (http://localhost:4000/admin)
├── داشبورد            ← آمار کلی: آزمون‌ها، شرکت‌کنندگان، میانگین نمره
├── دوره‌ها             ← گروه‌بندی آزمون‌ها (هر دوره چند آزمون)
├── آزمون‌ها            ← ساخت/ویرایش آزمون و نظرسنجی
│   └── ویرایشگر آزمون
│       ├── تب سوال‌ها      ← افزودن/ویرایش/ترتیب سوال‌ها
│       ├── تب کدهای دسترسی ← کد عمومی و کد اختصاصی
│       ├── تب هوش مصنوعی   ← استخراج سوال از عکس/PDF، تولید سوال، پیشنهاد نمره
│       ├── تب نتایج        ← تحلیل، داوری، خروجی Excel
│       └── تب تنظیمات      ← مدت، نمره‌ی قبولی، اطلاعات فراگیر، انتشار
├── پاسخ‌ها و داوری      ← صفحه‌ی جدا برای داوری سریع پاسخ‌های تشریحی
└── تنظیمات             ← کاربران، کلید هوش مصنوعی، وضعیت سرویس‌ها
```

## ⏱ چرخه‌ی کامل یک آزمون

| مرحله | کار | صفحه |
|---|---|---|
| ۱ | ساخت دوره | آزمون‌ها ← دوره‌ها |
| ۲ | ساخت آزمون و اتصال به دوره | آزمون‌ها ← + آزمون جدید |
| ۳ | وارد کردن سوال‌ها | تب سوال‌ها |
| ۴ | تعیین مدت، نمره‌ی قبولی و اطلاعات لازم | تب تنظیمات |
| ۵ | ساخت کد دسترسی | تب کدهای دسترسی |
| ۶ | انتشار (وضعیت = منتشر شده) | تب تنظیمات |
| ۷ | دادن کد به فراگیران | پیام/کانال/برگه |
| ۸ | پایش نتایج حین آزمون | تب نتایج |
| ۹ | داوری پاسخ‌های تشریحی | پاسخ‌ها و داوری |
| ۱۰ | نهایی‌سازی و خروجی Excel | تب نتایج |
