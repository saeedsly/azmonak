# ساخت و بارگذاری سوال

سه راه برای وارد کردن سوال وجود دارد. **روش هوش مصنوعی سریع‌ترین** است.

---

## انواع سوال پشتیبانی‌شده

| نوع | برای چه؟ | نکته‌ی داوری |
|---|---|---|
| **تک‌پاسخ** | یک گزینه‌ی درست | خودکار |
| **چندپاسخ** | چند گزینه‌ی درست | خودکار (با تنظیم «نمره‌ی جزئی» می‌توانید بخشی از نمره را بدهید) |
| **درست/نادرست** | سوال دوگزینه‌ای | خودکار |
| **پاسخ کوتاه** | یک کلمه/یک جمله | خودکار (مقایسه‌ی متنی) |
| **پاسخ تشریحی** | جواب بلند | 🔶 **نیاز به داوری انسانی** |
| **بارگذاری فایل** | پروژه/فایل پاسخی | 🔶 **نیاز به داوری انسانی** |
| **طیف لیکرت (Rating)** | میزان رضایت | بدون نمره (ویژه‌ی نظرسنجی) |
| **ماتریسی** | چند سوال با چند ستون | خودکار |
| **پاسخ عددی** | عدد | خودکار (با تلورانس اختیاری) |

---

## روش ۱ — ورود دستی (تکی)

`پنل مدیریت ← آزمون ← تب سوال‌ها ← + سوال جدید`

1. **نوع** سوال را انتخاب کنید.
2. **متن سوال** را بنویسید (می‌توانید از فرمت متن ساده استفاده کنید).
3. برای سوال گزینه‌دار:
   - گزینه‌ها را یکی‌یکی اضافه کنید (یا از دکمه‌ی «افزودن از متن» استفاده کنید)
   - روی گزینه‌ی درست تیک بزنید ← ⚠️ **مهم‌ترین قسمت کار**
4. **بارم** را تعیین کنید (پیش‌فرض ۱).
5. **دشواری** (۱ تا ۵) و **برچسب** را در صورت نیاز پر کنید.
6. **توضیح/پاسخ تشریحی** بنویسید (اگر می‌خواهید بعد از آزمون به فراگیر نمایش داده شود).

---

## روش ۲ — ورود گروهی (سریع‌تر از تکی)

در همان تب سوال‌ها، دکمه‌ی **«افزودن گروهی»**:

- سوال‌ها را به‌صورت متن ساده بنویسید، هر سوال با یک خط خالی از هم جدا شود:

```
سوال اول چیست؟
گزینه ۱
گزینه ۲
گزینه ۳

سوال دوم چیست؟
گزینه ۱
گزینه ۲
```

- برنامه سوال‌ها و گزینه‌ها را جدا می‌کند؛ **کلید پاسخ را خودتان تیک بزنید**.
- یا از قالب شماره‌گذاری‌شده استفاده کنید:

```
۱) سوال اول
الف) گزینه ۱
ب) گزینه ۲
۲) سوال دوم
الف) گزینه ۱
```

## روش ۳ — ورود با هوش مصنوعی (سریع‌ترین) ⭐

`پنل مدیریت ← آزمون ← تب هوش مصنوعی`

### ۳-۱) استخراج سوال از عکس یا PDF

1. **کلید API** را در `تنظیمات ← هوش مصنوعی` وارد کنید (یا در `.env`:
   `ANTHROPIC_API_KEY=...` و `AI_PROVIDER=anthropic`).
2. در تب هوش مصنوعی، فایل **عکس برگه** یا **PDF** را انتخاب کنید
   (یا حتی متن سوال‌ها را در کادر «دستور» بنویسید).
3. دکمه‌ی **«استخراج سوال‌ها»** → برنامه سوال‌ها، گزینه‌ها، بارم و **کلید پاسخ** را استخراج می‌کند.
4. نتیجه را **مرور کنید** — مدل ممکن است اشتباه کند:
   - متن سوال‌ها را اصلاح کنید
   - گزینه‌ی درست را چک کنید
   - بارم‌ها را تنظیم کنید
5. دکمه‌ی **«افزودن به آزمون»**.

> 📌 پشتیبانی از تصویر و PDF فقط با **Anthropic (Claude)** فعال است؛
> OpenAI و Ollama برای همین نسخه فقط متن را می‌گیرند.

### ۳-۲) تولید سوال با موضوع دلخواه

1. موضوع را بنویسید (مثلاً «امنیت شبکه‌های سازمانی»).
2. تعداد سوال و سطح دشواری را مشخص کنید.
3. دکمه‌ی **«تولید سوال»** → سوال‌های پیشنهادی با گزینه و کلید پاسخ ساخته می‌شود.

### ۳-۳) پیشنهاد نمره برای پاسخ تشریحی

`پنل مدیریت ← پاسخ‌ها و داوری ← دکمه‌ی 🤖` → برای هر پاسخ، نمره‌ی پیشنهادی + بازخورد
می‌آید. شما می‌توانید عدد را تغییر دهید یا بپذیرید.

### ۳-۴) خلاصه‌سازی نتایج نظرسنجی

`تب نتایج نظرسنجی ← دکمه‌ی «خلاصه با هوش مصنوعی»` → چند نکته‌ی کلیدی + پیشنهاد اقدام.

## 🗂 ترتیب و مدیریت سوال‌ها

| کار | روش |
|---|---|
| جابه‌جایی سوال‌ها | دکمه‌ی «↑/↓» یا کشیدن (Drag & Drop) در فهرست سوال‌ها |
| غیرفعال کردن سوال | ویرایش ← تیک «فعال» را بردارید (پاک نمی‌شود) |
| حذف سوال | دکمه‌ی حذف ⚠️ پاسخ‌های ثبت‌شده هم پاک می‌شود |
| کپی کردن آزمون | در لیست آزمون‌ها ← «کپی» (سوال‌ها هم کپی می‌شوند) |

## 📋 چک‌لیست قبل از انتشار

- [ ] همه‌ی سوال‌ها بارم دارند
- [ ] گزینه‌ی درست هر سوال چک شده
- [ ] مجموع بارم‌ها با نمره‌ی قبولی هم‌خوان است
- [ ] سوال‌های تشریحی برای داوری انسانی مشخص‌اند
- [ ] یک بار کل آزمون را خودم امتحان کرده‌ام
