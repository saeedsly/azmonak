# نظرسنجی

نظرسنجی در ازمونک **همان زیرساخت آزمون** را دارد، فقط نمره ندارد و می‌تواند **ناشناس** باشد.

---

## تفاوت آزمون و نظرسنجی

| | آزمون | نظرسنجی |
|---|---|---|
| نمره | ✅ دارد | ❌ ندارد (`score = 0`) |
| وضعیت قبولی | ✅ دارد | ❌ ندارد |
| گزینه‌ی درست | دارد | ندارد (پاسخ‌ها فقط جمع می‌شوند) |
| شرکت ناشناس | ❌ (به‌صورت پیش‌فرض) | ✅ پشتیبانی می‌شود |
| خروجی | نمره‌ی هر نفر | **گزارش تجمیعی گزینه‌ها** + متن پاسخ‌ها |
| زمان | تایمر دارد | اختیاری (معمولاً ۵–۱۰ دقیقه) |

---

## ساخت نظرسنجی

1. `پنل مدیریت ← آزمون‌ها ← + آزمون جدید`
2. **نوع = نظرسنجی**
3. در تب تنظیمات:
   - **مدت**: معمولاً ۵ تا ۱۰ دقیقه
   - **حداکثر دفعات شرکت**: `0` (نامحدود) — برای نظرسنجی معمولاً همین
   - **شرکت ناشناس**: ✅ روشن
   - **دریافت نام/ایمیل**: خاموش (تا واقعاً ناشناس باشد)
4. تب سوال‌ها: سوال‌ها را اضافه کنید — بهترین نوع‌ها برای نظرسنجی:
   - **طیف لیکرت (Rating)** — «میزان رضایت شما از کیفیت دوره؟» ۱ تا ۵
   - **چندپاسخ** — «کدام بخش‌ها برایتان مفید بود؟»
   - **پاسخ کوتاه/تشریحی** — «پیشنهاد شما برای بهبود دوره چیست؟»
   - **درست/نادرست** — «آیا این دوره برای شما مفید بود؟»
5. انتشار (منتشر شده) + کد دسترسی

---

## رفتار شرکت ناشناس

وقتی «شرکت ناشناس» روشن باشد:
- فراگیر **هیچ اطلاعات هویتی** وارد نمی‌کند (حتی اگر فیلدها فعال باشند)
- نام، ایمیل، تلفن و کد ملی **در دیتابیس ذخیره نمی‌شود**
- در فهرست تلاش‌ها به‌جای نام، **«ناشناس»** نمایش داده می‌شود
- در خروجی Excel نیز نامی وجود ندارد
- فقط **پاسخ‌ها** در گزارش تجمیعی محاسبه می‌شوند

> این رفتار در سطح کد تست شده است تا واقعاً ناشناس باشد، نه فقط در نمایش.

---

## دیدن نتایج

`پنل مدیریت ← آزمون ← تب نتایج ← بخش نظرسنجی`

برای هر سوال:
- **تعداد پاسخ** (responseCount)
- **میانگین** امتیاز (برای طیف لیکرت)
- **تفکیک گزینه‌ها**: تعداد و درصد هر گزینه
- **متن پاسخ‌های تشریحی** (تا ۵۰ مورد) برای خواندن و استخراج نکات

### خلاصه‌سازی با هوش مصنوعی
دکمه‌ی **«خلاصه با هوش مصنوعی»** → یک تحلیل کوتاه فارسی از:
- تعداد کل پاسخ‌ها
- میانگین هر سوال
- تفکیک گزینه‌ها

و در پایان چند «نکته‌ی کلیدی + پیشنهاد اقدام» پیشنهاد می‌دهد.

> ⚠️ برای این بخش باید `AI_PROVIDER` و کلید API تنظیم باشد؛ در غیر این صورت پیام
> «حالت نمایشی» می‌گیرید و بقیه‌ی برنامه کار می‌کند.

## نمونه‌ی آماده در seed

بعد از `npm run seed` یک نظرسنجی نمونه با کد `AZM-JREH` ساخته می‌شود:
۵ سوال (چندپاسخ، درست/نادرست، طیف لیکرت) — برای تست سریع مناسب است.
