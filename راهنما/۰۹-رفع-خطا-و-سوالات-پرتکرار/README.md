## اولین کار هنگام بروز مشکل

۱. **پنجره‌ی سرویس را نگاه کنید** — پیام خطا معمولاً همان‌جا نوشته شده.
۲. **آدرس سلامت** را باز کنید: <http://localhost:4000/api/health>
   - اگر `{"ok":true}` برگشت → سرور سالم است و مشکل جای دیگری است (مثلاً شبکه یا مرورگر).
   - اگر باز نشد → سرور اجرا نشده یا crashed شده.
۳. اگر مشکل ادامه داشت، به
   [`رفع-خطا.md`](رفع-خطا.md) یا [`۰۹` بخش پرسش‌های پرتکرار](سوالات-پرتکرار.md) بروید.
