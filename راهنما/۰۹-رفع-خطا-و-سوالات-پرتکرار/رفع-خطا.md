# رفع خطا

---

## ۱) خطاهای نصب و اجرا

| پیام خطا | معنی | راه‌حل |
|---|---|---|
| `node is not recognized` | Node.js نصب نیست یا PATH به‌روز نشده | Node.js ۲۰+ را نصب کنید، ترمینال را ببندید و دوباره باز کنید، سیستم را ری‌استارت کنید |
| `'npm' is not recognized` | npm همراه Node نصب نشده | Node.js را دوباره نصب کنید (نسخه‌ی LTS) |
| `EADDRINUSE: address already in use :::4000` | پورت ۴۰۰۰ اشغال است | در `.env` مقدار `PORT=4001` بگذارید؛ یا برنامه‌ی قبلی را ببندید (`netstat -ano | findstr :4000` → `taskkill /PID <شماره> /F`) |
| `Cannot find module '...'` | کتابخانه‌ها نصب نشده | `npm install` را اجرا کنید |
| `better-sqlite3` نصب نشد | درایور بومی در این سیسته ساخته نشد | در حالت MySQL لازم نیست؛ برای SQLite: `npm install better-sqlite3` (و در صورت خطا، Build Tools ویندوز) |
| `Error [ERR_MODULE_NOT_FOUND]: Cannot find package 'better-sqlite3'` | حالت SQLite است ولی درایور نصب نیست | پیام فارسی برنامه راهنمایی می‌کند؛ یا در `.env` مقدار `DB_MODE=mysql` را بگذارید |
| `Unsupported engine` / هشدار npm | نسخه‌ی Node قدیمی است | Node.js ۲۰ یا بالاتر نصب کنید |

## ۲) خطاهای دیتابیس

| پیام خطا | معنی | راه‌حل |
|---|---|---|
| `ECONNREFUSED 127.0.0.1:3306` | سرویس MySQL روشن نیست | XAMPP → MySQL → Start (یا Services ویندوز) |
| `Access denied for user 'azmoonak'@'localhost'` | نام کاربر/رمز در `MYSQL_URL` اشتباه است | مطابق راهنمای نصب، کاربر را دوباره بسازید |
| `Unknown database 'azmoonak'` | دیتابیس ساخته نشده | در phpMyAdmin دیتابیس را بسازید (راهنمای نصب) |
| `ER_ACCESS_DENIED_ERROR` هنگام seed | دسترسی کاربر کافی نیست | `GRANT ALL PRIVILEGES ON azmoonak.* TO 'azmoonak'@'localhost'; FLUSH PRIVILEGES;` |
| `Unknown column 'updatedAt'` | نصب قدیمی بدون مهاجرت ۲ | سرور را دوباره اجرا کنید (مهاجرت‌ها خودکار اجرا می‌شوند) یا `npm run seed` |
| `SQLITE_CANTOPEN` | مسیر فایل SQLite درست نیست | `SQLITE_FILE=./data/azmoonak.db` (نسبت به پوشه‌ی `server`) |
| `Table 'azmoonak.exams' doesn't exist` | جدول‌ها ساخته نشده | سرور را یک‌بار کامل اجرا کنید (مهاجرت در استارت انجام می‌شود) |

## ۳) خطاهای «کد معتبر نیست» و «منتشر نشده»

| پیام | دلیل | راه‌حل |
|---|---|---|
| «این آزمون هنوز منتشر نشده است.» | وضعیت آزمون «پیش‌نویس» است | در تب تنظیمات → وضعیت = **منتشر شده** |
| «کد معتبر نیست» | کد اشتباه/منقضی | کد را با حروف بزرگ و بدون فاصله وارد کنید؛ در تب کدهای دسترسی بررسی کنید |
| «حداکثر تعداد شرکت در این آزمون را استفاده کرده‌اید.» | سقف تلاش پر شده | در تنظیمات، «حداکثر دفعات شرکت» را بیشتر کنید یا `0` (نامحدود) بگذارید |
| «این آزمون در بازه‌ی برگزاری نیست» | خارج از `startAt`/`endAt` | زمان‌بندی را اصلاح یا حذف کنید |
| «کد منقضی شده است» | کد اختصاصی به تاریخ انقضا رسیده | کد جدید بسازید |

## ۴) خطاهای فراگیر

| پیام | دلیل | راه‌حل |
|---|---|---|
| «نام و نام خانوادگی را وارد کنید» | سوال اجباری مدیر | فراگیر باید مشخصات را کامل کند؛ یا در تنظیمات آزمون، «دریافت نام» را خاموش کنید |
| «دسترسی به این تلاش معتبر نیست» | توکن تلاش منقضی یا ناقص است | صفحه را بازخوانی کنید و آزمون را دوباره شروع کنید |
| «نشست شما منقضی شده است» | ۲۴ ساعت از شروع گذشته یا سرور ری‌استارت شده | آزمون را دوباره شروع کنید (پاسخ‌های ثبت‌شده تا قبل باقی است) |
| تایمر تمام شد ولی نمره‌ای نیامد | ثبت نهایی خودکار در حال انجام است | چند ثانیه صبر کنید و صفحه را بازخوانی کنید |
| صفحه‌ی سفید | فایل‌های سایت build نشده | `npm run build` و بعد `scripts\start-windows.bat` |
| دکمه‌ها کار نمی‌کنند / خطای JS | کش مرورگر | `Ctrl + F5` ( hard refresh) |

## ۵) خطاهای هوش مصنوعی

| پیام | دلیل | راه‌حل |
|---|---|---|
| «سرویس هوش مصنوعی غیرفعال است» | `AI_PROVIDER=none` | در `.env` مقدار `anthropic` (یا `openai`) بگذارید و کلید API را وارد کنید |
| ۴۰۱ / ۴۰۳ از ارائه‌دهنده | کلید API اشتباه یا منقضی | کلید را دوباره بسازید و در `.env` بگذارید |
| خطای timeout | مدل کند است یا فایل بزرگ است | `AI_TIMEOUT_MS=180000` و فایل کوچک‌تر (زیر ۱۰MB) |
| تصویر/PDF شناسایی نمی‌شود | ارائه‌دهنده‌ی بدون پشتیبانی تصویر انتخاب شده | `AI_PROVIDER=anthropic` (Claude) — تنها providerی که تصویر و PDF را می‌خواند |
| خروجی JSON خراب | پاسخ مدل ناقص بود | دوباره تلاش کنید؛ یا سوال‌ها را دستی وارد کنید |

## ۶) خطاهای شبکه و دسترسی

| مشکل | راه‌حل |
|---|---|
| از کامپیوتر دیگر باز نمی‌شود | پورت را در فایروال باز کنید؛ `HOST=0.0.0.0` باشد؛ `APP_URL` درست باشد |
| «This site can’t provide a secure connection» | HTTPS ندارید؛ در `APP_URL` از `http://` استفاده کنید |
| فراگیرها پشت proxy سازمان‌اند | `TRUST_PROXY=true` در `.env` |
| درخواست‌ها زیاد و خطای «تعداد درخواست‌ها بیش از حد مجاز» | این محدودیت امنیتی است؛ کمی بعد دوباره تلاش کنید یا در کد `rateLimit` را تغییر دهید |

## ۷) دستورهای تشخیصی سریع

```bat
:: سلامت سرویس
curl http://localhost:4000/api/health

:: تست کامل API
npm run test:api

:: چه پروسه‌ای پورت ۴۰۰۰ را گرفته؟
netstat -ano | findstr :4000
taskkill /PID <PID> /F

:: لاگ MySQL (XAMPP)
C:\xampp\mysql\data\*.err

:: اجرای مستقیم سرور برای دیدن خطا
node server\dist\index.js

:: اجرای سرور در حالت توسعه (لاگ دقیق‌تر)
npm run dev
```
