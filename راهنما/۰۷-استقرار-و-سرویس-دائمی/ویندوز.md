# اجرای دائمی روی ویندوز

---

## روش الف — Task Scheduler (پیشنهادی؛ بدون نصب هیچ ابزار اضافه)

### ۱) ساخت برنامه
قبل از هر چیز مطمئن شوید برنامه build شده است:

```bat
npm run build
```

### ۲) ساخت Task
1. `Task Scheduler` را باز کنید → **Create Task** (نه Basic Task).
2. تب **General**:
   - Name: `Azmoonak`
   - ✅ «Run whether user is logged on or not»
   - ✅ «Run with highest privileges» (اگر روی پورت‌های پایین یا سرویس MySQL لازم است)
3. تب **Triggers** → **New** → «At startup» → OK
4. تب **Actions** → **New**:
   - Program: `C:\Program Files\nodejs\node.exe`
   - Arguments: `server\dist\index.js`
   - Start in: `C:\azmoonak` ← (مسیر واقعی پروژه)
5. تب **Settings**:
   - ✅ «If the task fails, restart every 1 minute»
   - ✅ «Do not start a new instance» (اجازه‌ی اجرای هم‌زمان چند نمونه ندهید)
6. OK → در پنجره‌ی Task Scheduler روی **Azmoonak** راست‌کلیک → **Run** (تست)

> 💡 برای اینکه خروجی برنامه را ببینید، در تب Actions گزینه‌ی
> «Run whether user is logged on or not» را بردارید و به‌جایش «Run only when user is logged on»
> بگذارید تا پنجره‌ی CMD باز بماند.

### ۳) تست
در مرورگر: <http://localhost:4000/api/health> باید `ok: true` برگرداند.

### ۴) مدیریت
| کار | مسیر |
|---|---|
| توقف | Task Scheduler → روی Azmoonak → **End** |
| شروع | **Run** |
| تغییر تنظیمات | **Properties** |
| حذف | **Delete** |

## روش ب — PM2 (حرفه‌ای‌تر؛ لاگ و ری‌استارت خودکار)

```bat
npm install -g pm2
pm2 start server\dist\index.js --name azmoonak
pm2 save
pm2 startup
```

| دستور | کار |
|---|---|
| `pm2 status` | وضعیت پروسه‌ها |
| `pm2 logs azmoonak` | دیدن لاگ زنده |
| `pm2 restart azmoonak` | ری‌استارت |
| `pm2 stop azmoonak` | توقف |
| `pm2 monit` | نمودار مصرف منابع |

> 💡 برای اینکه PM2 بعد از ری‌استارت شدن ویندوز بالا بیاید، `pm2 startup` را یک‌بار اجرا کنید و
> دستوری که چاپ می‌شود را در Command Prompt با دسترسی Administrator اجرا کنید.

## روش ج — NSSM (سرویس ویندوزی واقعی)

اگر می‌خواهید برنامه دقیقاً مثل یک سرویس ویندوز رفتار کند:

```bat
nssm install Azmoonak "C:\Program Files\nodejs\node.exe" "C:\azmoonak\server\dist\index.js"
nssm set Azmoonak AppDirectory C:\azmoonak
nssm set Azmoonak Start SERVICE_AUTO_START
nssm start Azmoonak
```

## ⚙️ نکته‌های مهم برای محیط واقعی

| موضوع | توصیه |
|---|---|
| `NODE_ENV` | در `.env` مقدار `production` باشد |
| `HOST` | `0.0.0.0` باشد تا از شبکه هم قابل دسترسی باشد |
| `SESSION_SECRET` | حتماً یک رشته‌ی تصادفی بلند (حداقل ۳۲ کاراکتر) |
| پورت | اگر ۴۰۰۰ را چیزی گرفته، `PORT=4001` و در Task Scheduler هم همان را در نظر بگیرید |
| فایروال | پورت را برای شبکه‌ی خصوصی باز کنید |
| MySQL | با XAMPP، سرویس MySQL هم باید خودکار بالا بیاید (MySQL → Service → Install در XAMPP) |
| رمز مدیر | بعد از اولین ورود عوض شود |
